# Attach to Existing Pull Request

Attach to the **already-open** pull request **#{props.prNumber}**. This step is read-only.

Read the PR to confirm it exists and is open, and capture its URL and head SHA:
`gh pr view {props.prNumber} --json number,url,headRefOid,state`.
If it is not open, stop and report the problem — do not create a new PR.

Do NOT create a new PR, do NOT push code, do NOT post a comment, do NOT request reviewers, and
NEVER merge (`gh pr merge` is forbidden). Reading the PR is the only action.

Report the PR number, URL, and head SHA.

REQUIRED OUTPUT:
{props.schema}

Return ONLY raw JSON matching the required output schema.
