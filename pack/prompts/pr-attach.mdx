# Attach to Existing Pull Request

Attach to the **already-open** pull request **#{props.prNumber}** and trigger AI review.

Steps (use `gh` / `git`):

1. Read the PR to confirm it exists and is open, and capture its URL and head SHA:
   `gh pr view {props.prNumber} --json number,url,headRefOid,state`.
   If it is not open, stop and report the problem — do not create a new PR.
2. Post the review-trigger comment:
   `gh pr comment {props.prNumber} --body "{props.reviewersMention} review"`.

Do NOT create a new PR, do NOT push code, and NEVER merge (`gh pr merge` is forbidden).
Posting the trigger comment is the only mutating action.

Report the PR number, URL, and head SHA.

REQUIRED OUTPUT:
{props.schema}

Return ONLY raw JSON matching the required output schema.
