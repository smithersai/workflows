# Re-sync a Re-flowed PR

Branch **{props.branch}** (open as PR **#{props.prNumber}**) was re-flowed by a stack amend
and now has new local commits. Update the open PR to match and ask for re-review.

Steps (use `git` and `gh` directly):

1. Force-push the rewritten branch safely:
   `git push --force-with-lease origin {props.branch}`.
2. Post one re-review comment:
   `gh pr comment {props.prNumber} --body "{props.reviewersMention} re-review — re-flowed from an upstream stack amend; please re-review."`

Then capture the new head SHA: `git rev-parse {props.branch}`.

ABSOLUTE RULE: Do NOT merge the PR. Never run `gh pr merge`, never enable auto-merge.
Force-pushing and commenting are the only actions.

{props.schema}
