# Await & Classify Stack PR Reviews

Monitor these stacked pull requests until the expected reviewers respond, then
classify each PR's review state. This is a read-only monitoring step — do NOT
modify code, do NOT comment, and NEVER merge.

PRs in this stack (bottom → top, JSON — each has `prNumber` and `branch`):
{props.prs}

Expected reviewers (logins/apps that must weigh in): {props.reviewers}

## Poll loop

Resolve `{{owner}}/{{repo}}` once via `gh repo view --json nameWithOwner`. Poll
roughly every {props.pollIntervalSec} seconds, for up to {props.maxAttempts}
attempts (sleep between attempts). On each attempt, for EACH PR number gather:

- `gh pr view <pr> --json reviews,latestReviews,reviewDecision,comments,headRefOid`
- review comments: `gh api repos/{{owner}}/{{repo}}/pulls/<pr>/comments`
- issue comments: `gh api repos/{{owner}}/{{repo}}/issues/<pr>/comments`

For each PR, only consider reviews/comments authored **at or after** that PR's
current head commit (`headRefOid`) — earlier ones are stale and were already
addressed in a prior round.

Stop polling as soon as, for **every** PR, every expected reviewer AND every
human who left a review/comment after that PR's head has reached a terminal
state (approved or has findings). If after {props.maxAttempts} attempts an
expected reviewer is still `pending` on any PR, stop and set `timedOut: true`
(don't hot-wait on humans who haven't shown up — they're handled out of band).

## Classification (per PR)

Emit one entry per PR in `prs`, echoing its `prNumber` and `branch`. For each
reviewer on that PR:

- `kind`: `bot` for app/bot accounts (e.g. claude, codex), else `human`.
- `status`: `approved` (LGTM, no open asks) | `findings` (requested changes or
  any unresolved issue) | `pending` (no response after the latest push).
- `findings`: each concrete issue (`path` if file-specific, plus `body`). If the
  reviewer tagged a severity (P1/P2/nit), keep it in the `body` text.

Set `allResolved: true` ONLY if, across ALL PRs, there are no `pending` and no
`findings` (every reviewer approved everything).

{props.schema}

Return ONLY raw JSON matching the required output schema.
